JavaScript

Rückgabe

return beendet den aktuellen Funktionsaufruf. Du kannst einen Wert zurückgeben oder mit return; früh abbrechen.

Beispiel ausprobieren

JavaScript

function feldIstFrei(inhalt) {
  return inhalt === "";
}
console.log(feldIstFrei("")); // true
console.log(feldIstFrei("X")); // false

Vorschau

Gut zu wissen

Die aufrufende Stelle kann das Ergebnis in einer Variable speichern oder direkt in einer Bedingung prüfen.
