Gültigkeitsbereich

Der Ort der Deklaration bestimmt, wo eine Variable verfügbar ist. Ein let innerhalb einer Funktion ist außerhalb der Funktion nicht erreichbar. Eine außen angelegte Variable kann ihren Wert zwischen Aufrufen behalten.

Beispiel ausprobieren

JavaScript

let punkte = 0;
function zaehlen() {
  let schritt = 1;
  punkte = punkte + schritt;
}
zaehlen();
zaehlen();
console.log(punkte); // 2

Vorschau

Gut zu wissen

Die Variable punkte lebt außerhalb der Funktion. Die Variable schritt entsteht bei jedem Aufruf neu.
