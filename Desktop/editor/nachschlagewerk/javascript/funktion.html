JavaScript

Funktion

Bündelt Anweisungen unter einem Namen. Beim Definieren legst du fest, was die Funktion tut. Ausgeführt wird sie beim Aufruf.

Beispiel ausprobieren

JavaScript

function begruessen() {
  console.log("Hallo!");
}
begruessen();

Vorschau

Gut zu wissen

Die Klammern am Ende des Namens gehören zum Aufruf. Die geschweiften Klammern fassen den Funktionskörper zusammen.
