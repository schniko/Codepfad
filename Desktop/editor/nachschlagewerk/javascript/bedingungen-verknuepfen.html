Bedingungen verknüpfen

&& verlangt, dass beide Bedingungen stimmen. Bei || genügt mindestens eine. ! kehrt einen Wahrheitswert um.

Beispiel ausprobieren

JavaScript

let zahl = 42;
let imBereich = zahl >= 1 && zahl <= 100;
let ausserhalb = zahl < 1 || zahl > 100;
console.log(imBereich, ausserhalb); // true false

Vorschau

Gut zu wissen

Eine Bereichsprüfung braucht zwei vollständige Vergleiche. Schreibe zahl >= 1 && zahl <= 100.
