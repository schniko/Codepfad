Eingabewert

Die Eigenschaft .value enthält den aktuellen Text eines Eingabefelds. Auch bei type="number" erhältst du zunächst eine Zeichenkette.

Beispiel ausprobieren

JavaScript

let eingabe = document.getElementById("tipp");
let text = eingabe.value;
eingabe.value = "";
console.log(text);
Begleitcode anzeigen

HTML zum Beispiel

<label for="tipp">Tipp</label>
<input id="tipp" value="42">

Vorschau

Gut zu wissen

Im Beispiel wird der Text erst gelesen und dann das Feld geleert. Eine Kopie des gelesenen Textes bleibt in der Variable verfügbar.
