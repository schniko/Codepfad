Spielzustand

Variablen und Arrays können speichern, wer dran ist, welche Felder belegt sind und ob das Spiel beendet ist. Beim Neustart setzt du die Werte zurück und aktualisierst die Anzeige.

Beispiel ausprobieren

JavaScript

let spieler = "X";
let beendet = false;
let brett = ["", "", ""];
brett[0] = spieler;
spieler = "O";
console.log(brett, spieler, beendet);

Vorschau

Gut zu wissen

Bei einer Aktion änderst du zuerst die gespeicherten Werte und danach die Anzeige. So stimmen beide überein.
