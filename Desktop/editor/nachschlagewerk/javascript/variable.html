JavaScript

Variable

Gibt einem Wert einen Namen. Mit let deklarierst du eine Variable. Mit = weist du ihr einen Wert zu, den du später ändern kannst.

Beispiel ausprobieren

JavaScript

let name = "Mika";
name = "Jona";
console.log(name);

Vorschau

Eine Variable beim Klicken ändern

Der Zähler startet bei null und behält seinen Wert zwischen zwei Klicks. Jeder Klick erhöht ihn um eins.

JavaScript

let punkte = 0;
function zaehlen() {
  punkte = punkte + 1;
  document.getElementById("stand").textContent = punkte;
}
Begleitcode anzeigen

HTML zum Beispiel

<button type="button" onclick="zaehlen()">Punkt hinzufügen</button>
<p>Punkte: <span id="stand">0</span></p>

Vorschau

Gut zu wissen

Verwende Namen, die den Inhalt verraten, etwa punkte oder spieler. Beim Ändern einer vorhandenen Variable steht kein zweites let.
