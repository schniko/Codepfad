JavaScript

Text eines Elements

textContent liest den Text eines Elements oder ersetzt ihn durch neuen Text.

Beispiel ausprobieren

JavaScript

let meldung = document.getElementById("meldung");
meldung.textContent = "Abflug!";
Begleitcode anzeigen

HTML zum Beispiel

<p id="meldung">Bereit.</p>

Vorschau

Gut zu wissen

textContent behandelt den zugewiesenen Wert als Text. Ein enthaltenes HTML-Tag wird dabei nicht als Markup ausgeführt.
