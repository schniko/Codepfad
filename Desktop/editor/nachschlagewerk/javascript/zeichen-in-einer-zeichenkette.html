Zeichen in einer Zeichenkette

Mit eckigen Klammern liest du das Zeichen an einer Stelle. Die erste Stelle hat den Index 0. .length gibt bei den hier verwendeten Buchstaben die Anzahl an.

Beispiel ausprobieren

JavaScript

let wort = "abcd";
console.log(wort[0]); // "a"
console.log(wort.length); // 4

Vorschau

Gut zu wissen

Der letzte gültige Index ist length - 1. Bei vier Buchstaben ist das der Index 3.
