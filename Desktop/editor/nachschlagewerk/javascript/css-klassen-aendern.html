JavaScript

CSS-Klassen ändern

Mit classList.add fügst du eine Klasse hinzu, mit remove entfernst du sie und mit contains prüfst du, ob sie vorhanden ist.

Beispiel ausprobieren

JavaScript

let feld = document.getElementById("feld");
feld.classList.add("rot");
console.log(feld.classList.contains("rot"));
setTimeout(function () {
  feld.classList.remove("rot");
}, 1200);
Begleitcode anzeigen

HTML zum Beispiel

<div id="feld" class="feld">Farbfeld</div>

CSS zum Beispiel

.feld { padding: 10px; background: #e3f0e8; }
.rot { background: tomato; }

Vorschau

Gut zu wissen

Lege das Aussehen im CSS fest. JavaScript kann dann durch Klassen zwischen vorbereiteten Darstellungen wechseln.
