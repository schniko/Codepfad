CSS-Animation erneut auslösen

Beim Entfernen und sofortigen Hinzufügen einer Klasse kann der Browser beide Änderungen zusammenfassen. Das Lesen von offsetWidth dazwischen stößt eine Layout-Berechnung an, damit die Animation neu starten kann.

Beispiel ausprobieren

JavaScript

function feiern() {
  let maschine = document.getElementById("maschine");
  maschine.classList.remove("gewonnen");
  void maschine.offsetWidth;
  maschine.classList.add("gewonnen");
}
Begleitcode anzeigen

HTML zum Beispiel

<div id="maschine">Gewonnen!</div>
<button type="button" onclick="feiern()">Feiern</button>

CSS zum Beispiel

@keyframes puls { 50% { transform: scale(1.1); } }
.gewonnen { animation: puls 0.35s; }
