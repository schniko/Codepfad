JavaScript

Seitenelement finden

getElementById sucht nach einer HTML-id. querySelector verwendet einen CSS-Selektor. Wird kein passendes Element gefunden, erhältst du null.

Beispiel ausprobieren

JavaScript

let ausgabe = document.getElementById("ausgabe");
let erstesFeld = document.querySelector(".feld");
console.log(ausgabe.textContent, erstesFeld.textContent);
Begleitcode anzeigen

HTML zum Beispiel

<p id="ausgabe">Abflug!</p>
<div class="feld">Erstes Feld</div>

Vorschau

Gut zu wissen

id bezeichnet ein einzelnes Element. querySelector liefert das erste Element, das zum Selektor passt.
