Eingabe in eine Zahl umwandeln

Number() wandelt passenden Text in eine Zahl um. Nicht umwandelbarer Text ergibt NaN. Prüfe eine leere Eingabe vorher, weil Number("") den Wert 0 ergibt.

Beispiel ausprobieren

JavaScript

let eingabe = document.getElementById("tipp");
let text = eingabe.value;
if (text !== "") {
  let versuch = Number(text);
  console.log(versuch);
}
Begleitcode anzeigen

HTML zum Beispiel

<label for="tipp">Tipp</label>
<input id="tipp" value="42">

Vorschau

Gut zu wissen

Nach der Umwandlung kannst du mit dem Ergebnis rechnen. NaN steht für „Not a Number“.
