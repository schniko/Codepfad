Zeichenkette

Speichert Text in Anführungszeichen. + verbindet Texte. Ist einer der beiden Werte Text, kann + auch eine Zahl als Text anhängen.

Beispiel ausprobieren

JavaScript

let spieler = "X";
let meldung = spieler + " ist dran";
console.log("4" + 1); // "41"
