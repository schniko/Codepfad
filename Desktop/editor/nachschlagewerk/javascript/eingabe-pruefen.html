Eingabe prüfen

Prüfe zuerst, ob überhaupt etwas eingegeben wurde. Number.isInteger prüft anschließend, ob die umgewandelte Zahl ganzzahlig ist. Mit Vergleichen kannst du den erlaubten Bereich prüfen.

Beispiel ausprobieren

JavaScript

function pruefen() {
  let eingabe = document.getElementById("tipp");
  let text = eingabe.value;
  if (text === "") return;
  let zahl = Number(text);
  if (!Number.isInteger(zahl) || zahl < 1 || zahl > 100) return;
  console.log("Gültige Zahl:", zahl);
}
Begleitcode anzeigen

HTML zum Beispiel

<label for="tipp">Zahl von 1 bis 100</label>
<input id="tipp" type="number" value="42">
<button type="button" onclick="pruefen()">Prüfen</button>

Vorschau

Gut zu wissen

Der Test auf eine leere Eingabe steht vor Number(). Dann folgen die Ganzzahlprüfung und die Grenzen des erlaubten Bereichs.
