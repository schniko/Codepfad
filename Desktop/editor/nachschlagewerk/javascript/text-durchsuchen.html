JavaScript

Text durchsuchen

includes() prüft, ob ein Textstück in einer Zeichenkette vorkommt. Die Methode liefert true oder false.

Beispiel ausprobieren

JavaScript

let ziel = "abcd";
console.log(ziel.includes("b")); // true

Vorschau

Gut zu wissen

includes prüft das Vorkommen, unabhängig von der Position. Für einen Treffer an genau derselben Stelle vergleichst du die Zeichen über ihren Index.
