If-Verzweigung

Führt Code aus, wenn eine Bedingung stimmt. else if prüft einen weiteren Fall und else fängt die übrigen Fälle ab.

Beispiel ausprobieren

JavaScript

let zahl = 7;
let ziel = 10;
if (zahl > ziel) {
  console.log("Zu groß");
} else if (zahl < ziel) {
  console.log("Zu klein");
} else {
  console.log("Treffer!");
}

Zwei Fälle mit else

Ändere den Wert im Eingabefeld und klicke auf Prüfen. Der Vergleich entscheidet, welche Meldung erscheint.

JavaScript

function pruefen() {
  let zahl = Number(document.getElementById("zahl").value);
  let meldung = document.getElementById("meldung");
  if (zahl >= 10) {
    meldung.textContent = "Zehn oder größer";
  } else {
    meldung.textContent = "Kleiner als zehn";
  }
}
Begleitcode anzeigen

HTML zum Beispiel

<label for="zahl">Zahl</label>
<input id="zahl" type="number" value="7">
<button type="button" onclick="pruefen()">Prüfen</button>
<p id="meldung"></p>

Gut zu wissen

Die Zweige werden von oben nach unten geprüft. Der erste passende Zweig wird ausgeführt.
