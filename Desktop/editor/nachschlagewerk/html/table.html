Tabellen

<table>, <tr>, <td>, <th>

Eine Tabelle macht Informationen vergleichbar. Im Wochenplan unten steht jeder Tag in einer eigenen Zeile. Die Spalten verraten, wann und wo etwas stattfindet.

Einen Wochenplan aufbauen

Die gesamte Tabelle steht in <table>. Darin beginnt jede Zeile mit <tr>. In der ersten Zeile beschreiben <th>-Zellen die Spalten. In den folgenden Zeilen enthält jede <td>-Zelle den Wert für die passende Spalte. scope="col" macht die Zuordnung der Spaltenüberschriften ausdrücklich.

HTML

<table>
  <tr>
    <th scope="col">Tag</th>
    <th scope="col">Ort</th>
  </tr>
  <tr>
    <td>Montag</td>
    <td>Hafen</td>
  </tr>
  <tr>
    <td>Dienstag</td>
    <td>Leuchtturm</td>
  </tr>
</table>
