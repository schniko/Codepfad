Bereiche und Container

<div>

Fasst mehrere Elemente in einem neutralen Block zusammen. Mit class kannst du den Block in CSS auswählen.

Beispiel ausprobieren

HTML

<div class="karte">
  <h2>Steckbrief</h2>
  <p>Mira wohnt am Meer.</p>
</div>

Vorschau

Gut zu wissen

Ein div hat keine inhaltliche Bedeutung. Es ist praktisch, wenn mehrere Elemente einen gemeinsamen Rahmen oder Hintergrund bekommen sollen.
