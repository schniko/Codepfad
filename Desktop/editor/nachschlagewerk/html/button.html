Schaltflächen

<button>

Erzeugt eine Schaltfläche. Mit onclick kann ein Klick eine JavaScript-Funktion aufrufen.

Beispiel ausprobieren

HTML

<button type="button" onclick="starten()">Start</button>
<p id="meldung"></p>
<script>
  function starten() {
    document.getElementById("meldung").textContent = "Los geht’s!";
  }
</script>

Vorschau

Gut zu wissen

Mit type="button" ist ausdrücklich festgelegt, dass der Klick kein Formular abschickt. Eine Schaltfläche lässt sich auch per Tastatur bedienen.
