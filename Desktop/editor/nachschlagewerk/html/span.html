Einzelne Textstellen

<span>

Gruppiert eine kurze Textstelle, ohne einen neuen Absatz zu beginnen. Mit class lässt sich diese Stelle gezielt gestalten.

Beispiel ausprobieren

HTML

<p>Das ist <span class="wichtig">wichtig</span>.</p>

Vorschau

Gut zu wissen

Ein span beginnt keinen eigenen Block. Es eignet sich etwa für ein einzelnes farbiges Wort mitten in einem Satz.
