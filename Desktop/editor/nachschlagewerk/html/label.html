Beschriftungen für Eingabefelder

<label>

Beschriftet ein Eingabefeld. Der Wert von for entspricht der id des zugehörigen Felds.

Beispiel ausprobieren

HTML

<label for="tipp">Dein Tipp</label>
<input type="number" id="tipp">

Vorschau

Gut zu wissen

Wenn for und id übereinstimmen, setzt ein Klick auf die Beschriftung den Fokus ins Feld. So ist auch ohne Platzhalter klar, was eingegeben werden soll.
