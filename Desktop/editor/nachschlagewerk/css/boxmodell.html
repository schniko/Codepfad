Boxmodell

Bestimmt, was width und height umfassen. Bei border-box zählen Innenabstand und Rahmen zur angegebenen Größe.

Beispiel ausprobieren

CSS

.karte {
  box-sizing: border-box;
  width: 300px;
  padding: 12px;
}
Begleitcode anzeigen

HTML zum Beispiel

<div class="karte" style="background: #e3f0e8;">300 Pixel einschließlich Innenabstand</div>

Vorschau

Gut zu wissen

Bei content-box kommt der Innenabstand zur angegebenen Breite hinzu. Mit border-box bleibt die gesamte sichtbare Box innerhalb der Breite.
