Schrift in Kurzform

Fasst mehrere Schrifteinstellungen zusammen. Schriftgröße und Schriftfamilie gehören in die Kurzform. Hinter der Größe kann ein Schrägstrich mit der Zeilenhöhe stehen.

Beispiel ausprobieren

CSS

p { font: 16px/1.5 Arial, sans-serif; }
Begleitcode anzeigen

HTML zum Beispiel

<p>Diese Zeile verwendet Arial.
  <br>Die zweite Zeile zeigt den Abstand.</p>

Vorschau

Gut zu wissen

Die Schriftfamilie steht am Ende der Kurzform. Schreibe die Zeilenhöhe direkt nach dem Schrägstrich.
