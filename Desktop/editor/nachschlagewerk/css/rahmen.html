CSS

Rahmen

Zeichnet einen Rahmen. Die Kurzform kann Dicke, Linienart und Farbe festlegen. border-color ändert die Farbe eines bestehenden Rahmens.

Beispiel ausprobieren

CSS

.karte { border: 2px solid #245a69; }
Begleitcode anzeigen

HTML zum Beispiel

<div class="karte" style="padding: 10px;">Steckbrief</div>

Vorschau

Gut zu wissen

Ohne sichtbare Linienart bleibt ein Rahmen unsichtbar. solid zeichnet eine durchgehende Linie, dashed eine gestrichelte.
