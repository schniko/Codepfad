CSS

Hintergrund

Setzt den Hintergrund eines Elements. background-color ändert nur die Farbe. background ist die Kurzform für mehrere Hintergrundeinstellungen.

Beispiel ausprobieren

CSS

.karte { background-color: #e3f0e8; }
Begleitcode anzeigen

HTML zum Beispiel

<div class="karte" style="padding: 12px;">Ein heller Hintergrund</div>

Vorschau

Gut zu wissen

background-color ist praktisch, wenn du nur die Farbe ändern möchtest und andere Hintergrundeinstellungen behalten willst.
