CSS

Deckkraft

Macht ein ganzes Element samt Inhalt durchsichtiger. 1 ist vollständig sichtbar, 0 vollständig durchsichtig.

Beispiel ausprobieren

CSS

.slot { opacity: 0.5; }
Begleitcode anzeigen

HTML zum Beispiel

<p>Normale Deckkraft</p>
<p class="slot">Halbe Deckkraft</p>

Vorschau

Gut zu wissen

opacity macht auch Text und Bilder im Element durchsichtiger. Für einen durchsichtigen Hintergrund kannst du stattdessen eine Farbe mit Alphakanal wählen.
