CSS

Rasterelemente ausrichten

Richtet Elemente innerhalb ihrer Rasterzellen aus. center zentriert sie in beiden Richtungen.

Beispiel ausprobieren

CSS

.feld {
  display: grid;
  place-items: center;
}
Begleitcode anzeigen

HTML zum Beispiel

<div class="feld" style="min-height: 65px; background: #e3f0e8;">
  <span>X</span>
</div>

Vorschau

Gut zu wissen

In einer leeren oder zu kleinen Zelle fällt die Ausrichtung kaum auf. Das Beispiel gibt dem Feld deshalb eine feste Mindesthöhe.
