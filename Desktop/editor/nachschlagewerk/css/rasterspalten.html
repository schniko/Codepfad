CSS

Rasterspalten

Legt die Anzahl und Breite der Spalten in einem CSS-Grid fest.

Beispiel ausprobieren

CSS

.brett {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
.brett span { padding: 6px; background: #e3f0e8; }
Begleitcode anzeigen

HTML zum Beispiel

<div class="brett">
  <span>Spalte 1</span><span>Spalte 2</span><span>Spalte 3</span>
  <span>Spalte 1</span><span>Spalte 2</span><span>Spalte 3</span>
</div>

Vorschau

Gut zu wissen

1fr ist ein Anteil am freien Platz im Raster. repeat(3, 1fr) erzeugt drei gleich breite Spalten.
