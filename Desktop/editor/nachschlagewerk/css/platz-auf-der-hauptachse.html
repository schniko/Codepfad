CSS

Platz auf der Hauptachse

Verteilt den freien Platz. Bei einer Flex-Zeile zentriert center die Elemente horizontal.

Beispiel ausprobieren

CSS

.leiste {
  display: flex;
  justify-content: center;
}
Begleitcode anzeigen

HTML zum Beispiel

<div class="leiste" style="border: 1px solid #62917b;">
  <button type="button">Links</button>
  <button type="button">Rechts</button>
</div>

Vorschau

Gut zu wissen

Bei einer Flex-Spalte ist die Hauptachse senkrecht. Dasselbe center verteilt den freien Platz dann vertikal.
