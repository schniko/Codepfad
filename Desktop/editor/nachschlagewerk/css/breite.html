CSS

Breite

Legt die Breite oder ihre Grenzen fest. max-width verhindert, dass ein Element breiter als der angegebene Wert wird.

Beispiel ausprobieren

CSS

.karte {
  width: 100%;
  max-width: 400px;
}
Begleitcode anzeigen

HTML zum Beispiel

<div class="karte" style="background: #e3f0e8;">Diese Karte ist höchstens 400 Pixel breit.</div>

Vorschau

Gut zu wissen

Eine Prozentbreite bezieht sich auf den verfügbaren Platz. Die Kombination aus width: 100% und max-width hält ein Element auf großen Bildschirmen kompakt.
