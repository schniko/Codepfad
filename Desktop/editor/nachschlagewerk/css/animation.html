Animation

Spielt eine Folge von Zuständen ab. @keyframes beschreibt diese Zustände und animation verbindet sie mit einem Element.

Beispiel ausprobieren

CSS

@keyframes puls {
  from { transform: scale(1); }
  to { transform: scale(1.1); }
}
.slot { animation: puls 0.5s 3; }
Begleitcode anzeigen

HTML zum Beispiel

<div class="slot" style="margin: 12px 20px;">Ich pulsiere beim Start.</div>

Vorschau

Gut zu wissen

Ein Übergang reagiert auf eine Änderung. Eine Animation kann ihre Abfolge beim Laden selbstständig abspielen.
