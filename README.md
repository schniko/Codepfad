# Codepfad

Codepfad ist eine Lernumgebung für **HTML, CSS und JavaScript**. In kurzen Übungen entstehen erste Webseiten und kleine Spiele. Die Lernpfade eignen sich für den Unterricht und zum selbstständigen Ausprobieren.

**[Codepfad im Browser öffnen](https://codepfad.eu/)**

## Was du mit Codepfad machen kannst

- **HTML** – Texte strukturieren, Bilder einbinden und Seiten verlinken.
- **CSS** – Webseiten gestalten und mit Farben, Abständen und Übergängen experimentieren.
- **JavaScript** – Auf Klicks reagieren, Eingaben auswerten und Spiele wie Zahlenraten oder Tic-Tac-Toe bauen.

Aufgabe, Code und Live-Vorschau stehen nebeneinander. Änderungen am Code siehst du sofort in der Vorschau. Bei JavaScript-Übungen zeigt eine Konsole die Ausgaben deines Programms. Über **Schritt speichern** kannst du deinen Code samt Bildern als ZIP sichern und später im freien Editor wieder öffnen.

## Browser und Desktop

Die Webversion läuft direkt im Browser. Das Repository enthält außerdem eine Desktop-Variante auf Basis von Tauri für macOS und Windows. Beide Varianten nutzen dieselben Lernpfade und dieselbe Editoroberfläche.

## Im Repository

- [Lernpfade](Lernpfade/) – Aufgaben, Beispielcode und Illustrationen.
- [Editor](Desktop/editor/) – Bibliothek, Code-Editor und Live-Vorschau.
- [Desktop-App](Desktop/src-tauri/) – Tauri-Anwendung für macOS und Windows.
